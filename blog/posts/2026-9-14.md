# 安装并启动 audit

```bash
sudo pacman -S audit
sudo systemctl enable --now auditd
```

# 开始监控

```bash
sudo auditctl -w /home/imitoy -p wa -k dotfile_watch
```

之后加入到 sudoers，配置每次开机启动

```txt
imitoy ALL=(root) NOPASSWD: /usr/bin/auditctl -w /home/imitoy -p wa -k dotfile_watch
```

现在开始监控了，创建一个试试，然后查看到底是哪一个进程在创建
```bash
sudo ausearch -k dotfile_watch -f /home/imitoy/.a
```
