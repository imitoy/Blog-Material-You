1. 安装 acme.sh
 ```bash
 sudo pacman -S acme.sh
 ```

2. 指定配置文件到 `~/.config/acme.sh/`，不污染主目录。由于每次都需要指定配置目录，所以可以放到 `~/.bashrc` 中。
```bash
alias acme.sh='acme.sh --home ~/.config/acme.sh/home --config-home ~/.config/acme.sh/conf --cert-home ~/.config/acme.sh/certs'
```

手动创建这些目录：
```bash
mkdir -p ~/.config/acme.sh/home
mkdir -p ~/.config/acme.sh/conf
mkdir -p ~/.config/acme.sh/certs
```

3. 切换为 Let's encrypt
```bash
acme.sh --set-default-ca --server letsencrypt
```

4. 注册账号
```bash
acme.sh --register-account --email your-email@your-address.com
```

5. 打开 Namesilo，控制台 -> API Manager，滑到下边找到 API Key，勾选 Submitting this form constitutes your acceptance of our API terms of use（不要勾选 Read Only），点击 Generate，复制你的 Key
6. 设置环境变量，只设置一次就行，acme.sh 会自动保存你的 Key，因此不用添加到 `~/.bashrc`
```bash
export Namesilo_Key=your-namesilo-key
```
7. 申请证书（DNS 刷新等待时间不够可以增加时长）
```bash
acme.sh --issue --dns dns_namesilo -d your-domain.com -d *.your-domain.com --dnssleep 900
```

8. 安装证书
推荐使用 acme.sh 安装命令安装证书而避免直接复制，因为这样做会让 acme.sh 自动记住这些操作，而在每次定时任务后都能自动执行。

```bash
acme.sh --install-cert -d imitoy.top --key-file /var/ssl/imitoy.top.key --fullchain-file /var/ssl/imitoy.top.pem --reloadcmd "sudo systemctl reload openresty"
```

9. 配置无需密码即可 `sudo` 重新加载 Web 服务。因为安装时是用用户身份安装的，执行需自动化 root 执行。
10. 设置自动续期服务和定时任务。
11. 手动触发定时任务进行测试。
