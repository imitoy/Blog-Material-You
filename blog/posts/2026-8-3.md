为学校 ACM 战队部署在线自测平台，使用 docker 部署开源的 HydroOJ 平台，采用云服务器后端与评测机+本地评测机的方式。这样做能够保证全时段稳定运行，也能在高峰时段正常运行（一般情况下比赛的时候本地机器会开着）

~~不得不说文档比 Hexo 还烂~~

为什么使用 docker？因为安装需要 root 权限。我不希望一个软件能够破坏系统环境。
# 准备

- 一台服务器（Arch Linux）
- 本地电脑（Arch Linux）

# 配置服务器

使用 docker compose 一键部署，记得修改端口映射。

```bash
git clone https://github.com/hydro-dev/Hydro.git
cd Hydro/install/docker
docker compose up -d
```

配置 nginx 反向代理（`/opt/openresty/nginx/conf/sites-available/oj.conf` 如下）

```conf
server {
	listen 80;
	listen [::]:80;
	server_name oj-domain.top www.oj-domain.top; # 换成你的域名

	return 301 https://$host$request_uri;
}

server {
	listen 443 ssl;
	listen [::]:443 ssl;
	server_name oj-domain.top www.oj-domain.top;    # 换成你的域名
	ssl_certificate /var/ssl/oj-domain.top.pem;     # SSL
	ssl_certificate_key /var/ssl/oj-domain.top.key; # SSL

	location / {
		proxy_pass http://127.0.0.1:8011;           # 你本地 docker 映射出的端口
		proxy_set_header Host $host;
		proxy_set_header X-Real-IP $remote_addr;
		proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
		proxy_set_header X-Forwarded-Proto $scheme;
		proxy_set_header Upgrade $http_upgrade;     # 这俩必须有，不
		proxy_set_header Connection "upgrade";      # 然评测机不能用
		proxy_read_timeout 3600s;
    	proxy_send_timeout 3600s;
	}
	#root /opt/openresty/nginx/html/;
	#index index.html;
	#autoindex off;

	#include /opt/openresty/nginx/conf/mime.types;
	#default_type application/octet-stream;
}
```

配置完之后打开浏览器访问你的网址，使用用户名 judge 密码 examplepassword 登录，修改密码为 12345678（你的密码，最好随机点）

然后回到后台，编辑 `Hydro/install/docker/judge/judge.yml` ，把初始密码 examplepassword 改成你刚才的密码

然后重启

```bash
docker compose down && docker compose up -d
```
# 配置本地评测机

本地也克隆一次仓库，然后编辑 docker-compose.yml：把其他的和 depends on 都去掉

```yml
services:
  oj-judge:
    build: ./judge
    container_name: oj-judge
    restart: always
    privileged: true
    volumes:
      - ./judge/judge.yaml:/root/.hydro/judge.yaml
      - ./judge/mount.yaml:/root/.hydro/mount.yaml
```

之后把 `Hydro/install/docker/judge/judge.yml` 也改成你刚刚的密码

然后部署：

```bash
docker compose up -d
```

就可以了。
